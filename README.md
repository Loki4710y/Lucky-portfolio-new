## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm or pnpm
- Git

### Clone the repository

```bash
git clone https://github.com/Loki4710y/Lucky-portfolio-new.git
cd Lucky-portfolio-new
```

### Install dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

### Start the development server

```bash
npm run dev
```

Or:

```bash
pnpm dev
```

The local development server will start and provide a URL in the terminal.

## Design Philosophy

The goal of this portfolio is to make the portfolio itself feel like a project.

Instead of presenting information as a traditional collection of sections, the interface uses a desktop metaphor where visitors can explore different parts of the portfolio through applications, windows, menus, and interactive elements.

The content is intentionally separated from much of the UI through Markdown/configuration files so that project information can be updated without rebuilding the entire interface structure.
