# About This Site

This is my personal portfolio, styled as an interactive macOS desktop. It's inspired by macOS [Big Sur](https://www.apple.com/in/macos/big-sur/) and [Catalina](https://www.apple.com/bw/macos/catalina/), built with [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), and [UnoCSS](https://uno.antfu.me/).

Explore the Finder, Terminal, and Notes apps to learn more about me and my projects, or check out the Dock for quick links.

Original template by [Renovamen](https://github.com/Renovamen/playground-macos), customized by Lucky Mishra.
