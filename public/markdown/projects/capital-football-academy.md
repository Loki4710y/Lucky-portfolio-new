# Capital Football Academy

A marketing website built for a football academy to showcase programs, coaching, and facilities, and to convert visitors into enquiries.

## Highlights

- Clean, sports-focused design with strong visual hierarchy
- Built with React + Vite for fast performance
- WhatsApp and contact-form integration for lead capture
- Fully responsive across mobile and desktop

## Stack

React, Vite, Framer Motion, EmailJS, Hostinger
